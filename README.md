
Projeto desenvolvido com o objetivo de estudar e praticar **Spring Boot** e seus principais recursos no desenvolvimento de uma API REST.

O projeto consiste em uma aplicação de **lista de tarefas (To-Do List)**, que será construída e aprimorada gradualmente conforme novos conceitos forem aprendidos durante os estudos.

### Objetivos

* Praticar o desenvolvimento de APIs REST com Spring Boot.
* Aprender a estruturar um projeto utilizando boas práticas.
* Trabalhar com Controllers, Services e Repositories.
* Aprender a trabalhar com banco de dados e JPA.
* Implementar operações CRUD.
* Aprender validações e tratamento de exceções.
* Evoluir o projeto gradualmente conforme novos conhecimentos forem adquiridos.

### Sobre os commits

Cada etapa do projeto representa um novo conceito ou recurso aprendido durante os estudos. Dessa forma, o histórico de commits também funciona como um registro da evolução do aprendizado em Spring Boot.
